# Kullanılan açık kaynaklar

- shadcn/ui — https://github.com/shadcn-ui/ui — MIT. Resmi CLI üzerinden eklenen Button ve Dialog kaynakları `src/components/ui/` altındadır; uygulama için yerelleştirilmiştir.
- Radix UI — https://github.com/radix-ui/primitives — MIT. Erişilebilir dialog davranışı.
- Recharts — https://github.com/recharts/recharts — MIT. Bakiye grafiği.
- Lucide — https://github.com/lucide-icons/lucide — ISC. İkonlar.
- React — https://github.com/facebook/react — MIT.
- Vite — https://github.com/vitejs/vite — MIT.
- Tailwind CSS — https://github.com/tailwindlabs/tailwindcss — MIT.

Tam bağımlılık sürümleri package-lock.json içinde; dağıtılan paketlerin lisansları node_modules içindeki ilgili paketlerde bulunur.
